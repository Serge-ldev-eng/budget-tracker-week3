# Smart Spend - Budget Tracker Week 3

What I built: Improved my Week 1-2 Budget Tracker with visual design only.

Color Palette: #F8FAFC background, #FFFFFF cards, #4F46E5 primary button, #1E293B headings, #EEF2FF table header, #E2E8F0 borders. Used consistently across background, headings, buttons, table header.

Typography: Google Fonts - Poppins for headings, Inter for body. Creates hierarchy and readability.

Table & Form: Table has 14x18 padding, styled header, borders, alternating rows, hover. Form has 12x14 padding, 10px radius, focus ring. Buttons cohesive.

Box Model: Each section is a card with margin-bottom 28px, padding 32px, border 1px, border-radius 16px, shadow. Header, Form, Table are distinct cards.
## Testing
- Added test expenses: Food (KES 1500), Transport (KES 500), Entertainment (KES 1200) - displays correctly in table with KES formatting.
- Persistence tested: Expenses remain after page refresh and browser restart (localStorage).
